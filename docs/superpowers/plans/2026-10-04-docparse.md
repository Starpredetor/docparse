# docparse Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Rust library and CLI that turns PDF, DOCX and image files into structure-preserving JSONL with a hard memory ceiling and no network access.

**Architecture:** Every input format reduces to a `Source` trait yielding one `Page` at a time. A streaming chunker consumes any `Source` and emits `Chunk`s on sentence boundaries with exact page attribution. Backends sit behind Cargo features so unused C dependencies are never linked. Parallelism is across files via `rayon`, not within a file, because the target hardware is I/O-bound.

**Tech Stack:** Rust 1.98, `serde`/`serde_json`, `thiserror`, `quick-xml`, `zip`, `clap`, `walkdir`, `rayon`, `pdfium-render`, `rusty-tesseract`, `criterion`, `peak_alloc`.

**Spec:** `docs/superpowers/specs/2026-10-04-docparse-design.md`

## Reading this plan if you are new to Rust

The user is fluent in Python and new to Rust. Each task has a **Rust notes** block explaining the concepts it introduces, the first time they appear. Read that block before the steps. Nothing is assumed from later tasks.

The single most useful mental model up front: Rust has no garbage collector and no exceptions. Every value has exactly one owner, and functions that can fail return `Result<T, E>` — a value you must handle, not something thrown past you. The `?` operator is the shorthand for "if this is an error, return it to my caller," which is roughly what a bare `raise` does in Python.

## Global Constraints

- Rust edition 2021, toolchain 1.98 or newer.
- **No network access at runtime.** No HTTP client crate may appear anywhere in `cargo tree`. This is an invariant from the spec, not a configuration flag.
- No LLM, no embeddings, no vector index, no image captioning, no HTTP server. These are explicit non-goals.
- Peak heap allocation stays under **64 MB** for any single input file regardless of its size.
- Identical input bytes produce byte-identical JSONL output when `--jobs 1`.
- No silent fallbacks. A missing capability is an error, never a placeholder value. The Python code's `_hash_fallback` (a seeded random vector returned when the embedding model is absent) is the specific anti-pattern this forbids.
- Cargo features: `pdf`, `docx`, `image` default-on; `ocr` default-off.
- Worker count defaults to `min(available_parallelism, 4)`, never all cores.
- The existing Python application is not modified or deleted by any task in this plan.

```
      error.rs                  # Error enum, Result alias

      chunk.rs                  # sentence splitter, ChunkConfig, Chunker

      image.rs                  # feature = "image"
      ocr.rs                    # feature = "ocr"
    tests/
      docx_test.rs              # builds .docx fixtures in-test, no binary files
      chunk_properties.rs       # coverage and determinism property tests

    benches/
```

One responsibility per file. `model.rs` holds data with no behaviour; `chunk.rs` holds the algorithm with no I/O; each backend knows one format and nothing about chunking. The CLI is the only place that touches the filesystem broadly or decides exit codes.

### Task 1: Workspace, data model, error type, `Source` trait

Foundation. No backends, no I/O — but it ends with passing tests, because the data model has real behaviour worth pinning down (its JSON shape).

**Files:**
- Create: `docparse/Cargo.toml`
- Create: `docparse/docparse/Cargo.toml`
- Create: `docparse/docparse/src/lib.rs`
- Create: `docparse/docparse/src/model.rs`
- Create: `docparse/docparse/src/error.rs`
- Create: `docparse/docparse/src/source.rs`

**Interfaces:**
- Consumes: nothing.
- Produces: `Rect`, `BlockKind`, `PageOrigin`, `Block`, `Page`, `BlockRef`, `Chunk`, `Error`, `Result<T>`, `trait Source { fn next_page(&mut self) -> Option<Result<Page>>; }`. Every later task depends on these exact names.

**Rust notes for this task:**

- A *workspace* is one `Cargo.toml` that groups several crates, like a monorepo with shared dependency resolution and one `target/` build directory.
- `#[derive(Debug, Clone, Serialize)]` auto-generates implementations. `Serialize` comes from `serde` and is how a struct becomes JSON — the equivalent of writing `to_dict()` by hand, except generated at compile time.
- `enum` in Rust is far stronger than Python's. Variants carry data: `PageOrigin::Ocr { confidence: 0.9 }` is one value of one type. This is how we make "where did this text come from" impossible to forget to check.
- `Option<T>` is `T` or nothing — Rust's replacement for `None`, except the compiler forces you to handle the empty case. `Option<Rect>` on a block means "DOCX genuinely has no coordinates," not "we didn't bother."
- `thiserror` generates the boilerplate that turns an enum into a proper error type. `#[error("...")]` defines the human-readable message.
- A `trait` is close to a Python ABC or Protocol: a set of methods a type promises to provide. `Source` is the one abstraction the whole library pivots on.
- `&mut self` means the method may mutate the receiver, and the compiler guarantees nobody else holds a reference to it at that moment. `next_page` must mutate, because it advances a position.

**Deviations from the spec, deliberate, for cleaner JSON:** the spec sketched `Heading(u8)`, `pages: (u32, u32)` and `blocks: Vec<(u32, u32)>`. Tuples serialize as positional arrays (`[3, 7]`), which is unreadable in output anyone has to debug. Use named fields instead: `Heading { level: u8 }`, `page_start`/`page_end`, and a `BlockRef { page, block }` struct. Same information, self-describing output.

```rust
use serde::{Deserialize, Serialize};

/// A bounding box in PDF points, origin at the page's bottom-left.
#[derive(Debug, Clone, Copy, PartialEq, Serialize, Deserialize)]
pub struct Rect {
    pub x0: f32,
    pub y0: f32,
    pub x1: f32,
    pub y1: f32,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum BlockKind {
    Paragraph,
    Heading { level: u8 },
    ListItem,
    TableCell { row: u32, col: u32 },
    Caption,
    Other,
}

/// Where a page's text actually came from. A consumer can distinguish
/// extracted text from an OCR guess; the Python pipeline concatenated a
/// BLIP caption with OCR output into one undifferentiated string.
#[derive(Debug, Clone, Copy, PartialEq, Serialize, Deserialize)]
#[serde(tag = "origin", rename_all = "snake_case")]
pub enum PageOrigin {
    /// Text extracted directly from the document.
    Native,
    /// No real page exists in the source format; this boundary was invented.
    Synthesized,
    Ocr { confidence: f32 },
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Block {
    /// Sequential within its page, starting at 0.
    pub id: u32,
    /// `None` when the source format has no geometry, as with DOCX.
    #[serde(skip_serializing_if = "Option::is_none")]
    pub bbox: Option<Rect>,
    pub kind: BlockKind,
    pub text: String,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Page {
    /// 1-based, and always the true source page number.
    pub number: u32,
    /// Points. Zero when the format has no page geometry.
    pub width: f32,
    pub height: f32,
    pub origin: PageOrigin,
    pub blocks: Vec<Block>,
}

/// Provenance: which block on which page a chunk's text came from.
#[derive(Debug, Clone, Copy, PartialEq, Serialize, Deserialize)]
pub struct BlockRef {
    pub page: u32,
    pub block: u32,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Chunk {
    pub id: u64,
    pub source: String,
    /// Inclusive span of real page numbers.
    pub page_start: u32,
    pub page_end: u32,
    pub blocks: Vec<BlockRef>,
    pub text: String,
    pub origin: PageOrigin,
    /// True when a single sentence exceeded `max_chars` and had to be cut.
    pub hard_split: bool,
}
```

### Task 2: DOCX backend

DOCX comes before PDF deliberately. It exercises the entire pipeline with no C dependency and no binding layer, so the first end-to-end slice has zero external build requirements.

**Files:**
- Modify: `docparse/docparse/src/docx.rs` (created empty in Task 1)
- Create: `docparse/docparse/tests/docx_test.rs`

**Interfaces:**
- Consumes: `Page`, `Block`, `BlockKind`, `PageOrigin`, `Error`, `Result`, `Source` from Task 1.
- Produces: `DocxSource` with `DocxSource::open(path: &Path) -> Result<DocxSource>`, implementing `Source`.

**Rust notes for this task:**

- A `.docx` is a ZIP archive. The text lives in `word/document.xml`. Nothing about this is proprietary; `zip` plus `quick-xml` is the whole toolkit, and it is genuinely less code than `python-docx`.
- `quick-xml` is a *pull* parser: you ask for the next event (`Start`, `Text`, `End`, `Eof`) in a loop. Think `iterparse`, not `minidom`. No document tree is ever built, so memory stays flat.
- `.map_err(|e| ...)` converts one error type into another. The closure syntax `|e| expr` is a lambda. We use it to attach the file path to every low-level failure.
- `local_name()` strips the XML namespace prefix, so `<w:p>` matches `b"p"`. The `b"p"` literal is a byte string — `quick-xml` works in bytes to avoid paying for UTF-8 validation on tags it will discard.
- `std::mem::take(&mut v)` moves a `Vec` out and leaves an empty one behind, with no copy. It is the idiomatic way to harvest an accumulator and keep going.

**A deliberate, bounded compromise, stated plainly:** `next_page` would need to resume XML parsing mid-stream across calls, which in Rust means a struct holding both the bytes and a parser borrowing those bytes — a self-referential type the borrow checker rejects, and the workarounds are not something to inflict on a first Rust task. So `DocxSource::open` parses all pages eagerly into a `Vec<Page>` and `next_page` hands them out one at a time. This is safe for the memory budget because DOCX text is small by nature (no embedded page images to extract), and bounded by the document's text size alone. PDF — the format where documents actually get large — streams properly in Task 6. If a pathological DOCX ever breaks the budget, the fix is a parser thread with a bounded channel; do not do it speculatively.

```rust
//! DOCX extraction. A `.docx` is a ZIP whose `word/document.xml` holds
//! the text; no C dependency is involved.

use std::fs::File;
use std::io::BufReader;
use std::path::Path;

use quick_xml::events::{BytesStart, Event};
use quick_xml::Reader;

use crate::error::{Error, Result};
use crate::model::{Block, BlockKind, Page, PageOrigin};
use crate::source::Source;

pub struct DocxSource {
    pages: std::vec::IntoIter<Page>,
}

impl DocxSource {
    pub fn open(path: &Path) -> Result<Self> {
        let file = File::open(path).map_err(|source| Error::Io {
            path: path.to_path_buf(),
            source,
        })?;

        let mut archive =
            zip::ZipArchive::new(BufReader::new(file)).map_err(|e| Error::Malformed {
                path: path.to_path_buf(),
                detail: format!("not a readable zip archive: {e}"),
            })?;

        let entry = archive
            .by_name("word/document.xml")
            .map_err(|_| Error::Malformed {
                path: path.to_path_buf(),
                detail: "missing word/document.xml".to_string(),
            })?;

        let pages = parse_document(BufReader::new(entry), path)?;
        Ok(Self {
            pages: pages.into_iter(),
        })
    }
}

impl Source for DocxSource {
    fn next_page(&mut self) -> Option<Result<Page>> {
        self.pages.next().map(Ok)
    }
}

/// Accumulated state for the paragraph currently being read.
#[derive(Default)]
struct Para {
    text: String,
    style: Option<String>,
    is_list: bool,
    ends_section: bool,
}

fn parse_document<R: std::io::BufRead>(reader: R, path: &Path) -> Result<Vec<Page>> {
    let mut xml = Reader::from_reader(reader);
    let mut buf = Vec::new();

    let mut pages: Vec<Page> = Vec::new();
    let mut blocks: Vec<Block> = Vec::new();
    let mut next_block_id: u32 = 0;
    let mut page_number: u32 = 1;

    let mut para = Para::default();
    let mut in_text = false;
    let mut in_table = false;
    let mut row: u32 = 0;
    let mut col: u32 = 0;

    let malformed = |e: quick_xml::Error| Error::Malformed {
        path: path.to_path_buf(),
        detail: e.to_string(),
    };

    loop {
        match xml.read_event_into(&mut buf).map_err(malformed)? {
            Event::Eof => break,

            Event::Start(e) => match e.local_name().as_ref() {
                b"p" => para = Para::default(),
                b"t" => in_text = true,
                b"tbl" => {
                    in_table = true;
                    row = 0;
                }
                b"tr" => col = 0,
                b"numPr" => para.is_list = true,
                b"sectPr" => para.ends_section = true,
                _ => {}
            },

            Event::Empty(e) => match e.local_name().as_ref() {
                b"pStyle" => para.style = attr_value(&e, b"val"),
                b"numPr" => para.is_list = true,
                b"tab" => para.text.push(' '),
                b"br" | b"cr" => para.text.push('\n'),
                _ => {}
            },

            Event::Text(t) if in_text => {
                // `unescape` turns &amp; back into &.
                para.text.push_str(&t.unescape().map_err(malformed)?);
            }

            Event::End(e) => match e.local_name().as_ref() {
                b"t" => in_text = false,
                b"tc" => col += 1,
                b"tr" => row += 1,
                b"tbl" => in_table = false,

                b"p" => {
                    let text = para.text.trim();
                    if !text.is_empty() {
                        let kind = if in_table {
                            BlockKind::TableCell { row, col }
                        } else if para.is_list {
                            BlockKind::ListItem
                        } else if let Some(level) = heading_level(para.style.as_deref()) {
                            BlockKind::Heading { level }
                        } else {
                            BlockKind::Paragraph
                        };
                        blocks.push(Block {
                            id: next_block_id,
                            bbox: None, // DOCX has no geometry; say so honestly.
                            kind,
                            text: text.to_string(),
                        });
                        next_block_id += 1;
                    }

                    // A sectPr marks the end of a section, which is the
                    // closest thing DOCX has to a page boundary.
                    if para.ends_section && !blocks.is_empty() {
                        pages.push(Page {
                            number: page_number,
                            width: 0.0,
                            height: 0.0,
                            origin: PageOrigin::Synthesized,
                            blocks: std::mem::take(&mut blocks),
                        });
                        page_number += 1;
                        next_block_id = 0;
                    }
                    para = Para::default();
                }

                _ => {}
            },

            _ => {}
        }
        buf.clear();
    }

    if !blocks.is_empty() {
        pages.push(Page {
            number: page_number,
            width: 0.0,
            height: 0.0,
            origin: PageOrigin::Synthesized,
            blocks,
        });
    }

    Ok(pages)
}

fn attr_value(e: &BytesStart<'_>, name: &[u8]) -> Option<String> {
    e.attributes()
        .flatten()
        .find(|a| a.key.local_name().as_ref() == name)
        .and_then(|a| String::from_utf8(a.value.to_vec()).ok())
}

/// `"Heading2"` -> `Some(2)`. Anything else -> `None`.
fn heading_level(style: Option<&str>) -> Option<u8> {
    let style = style?;
    let rest = style
        .strip_prefix("Heading")
        .or_else(|| style.strip_prefix("heading"))?;
    rest.trim()
        .parse::<u8>()
        .ok()
        .filter(|level| (1..=9).contains(level))
}
```

### Task 3: Per-block text normalization

**Files:**
- Create: `docparse/docparse/src/normalize.rs`
- Modify: `docparse/docparse/src/lib.rs` (add `pub mod normalize;`)

**Interfaces:**
- Consumes: nothing from earlier tasks.
- Produces: `pub fn normalize_block_text(input: &str) -> String`.

**Rust notes for this task:**

- `&str` is a borrowed string slice (a view into someone else's text, no copy). `String` is owned and growable. This function borrows its input and returns a new owned string, so the caller keeps their original.
- `String::with_capacity(n)` preallocates, avoiding repeated reallocation while pushing. Cheap habit, free performance.
- `match` on a `char` is exhaustive pattern matching; `'\u{201C}'` is a Unicode escape, here the left double curly quote.
- `char::is_whitespace` and `char::is_control` are Unicode-aware, unlike a hand-rolled ASCII check.

**Why this function is small but important.** The Python implementation runs `re.sub(r"\s+", " ", text)` across the *entire document* before chunking. That collapses every newline, so the whole document becomes one line and all paragraph, block and page structure — the very thing PyMuPDF was used to obtain — is destroyed before the chunker ever sees it. Normalizing strictly *within* one block is the fix, and it is why this is a separate function with a name that says "block" in it.

```rust
//! Text cleanup, scoped to a single block.
//!
//! Deliberately *not* document-wide: collapsing whitespace across an
//! entire document destroys the block and page structure the backends
//! worked to preserve.

/// Collapses internal whitespace runs to single spaces, maps common
/// typographic characters to ASCII, drops control characters, and trims
/// both ends. Block boundaries are the caller's business and are never
/// crossed here.
pub fn normalize_block_text(input: &str) -> String {
    let mut out = String::with_capacity(input.len());
    let mut pending_space = false;

    for ch in input.chars() {
        let replacement: &str = match ch {
            '\u{201C}' | '\u{201D}' | '\u{201E}' => "\"",
            '\u{2018}' | '\u{2019}' | '\u{201A}' => "'",
            '\u{2013}' | '\u{2014}' | '\u{2212}' => "-",
            '\u{2026}' => "...",
            '\u{00A0}' | '\u{2007}' | '\u{202F}' => " ",
            _ => {
                if ch.is_whitespace() {
                    // Remember it, but only emit one space, and only if
                    // something follows. This trims both ends for free.
                    pending_space = true;
                    continue;
                }
                if ch.is_control() {
                    continue;
                }
                if pending_space && !out.is_empty() {
                    out.push(' ');
                }
                pending_space = false;
                out.push(ch);
                continue;
            }
        };

        if pending_space && !out.is_empty() {
            out.push(' ');
        }
        pending_space = false;
        out.push_str(replacement);
    }

    out
}
```

Note what makes the trimming fall out of the algorithm rather than needing a separate pass: a pending space is only flushed when a real character follows *and* something has already been written. A leading run has nothing written yet; a trailing run never gets a following character.

### Task 4: Streaming sentence-boundary chunker

The heart of the project, and the component whose Python counterpart is most clearly wrong.

**Files:**
- Create: `docparse/docparse/src/chunk.rs`
- Create: `docparse/docparse/tests/chunk_properties.rs`
- Modify: `docparse/docparse/src/lib.rs`

**Interfaces:**
- Consumes: `Page`, `Block`, `Chunk`, `BlockRef`, `PageOrigin`, `Result`, `Source` from Tasks 1 and 3's `normalize_block_text`.
- Produces:
  - `pub fn split_sentences(text: &str) -> Vec<&str>`
  - `pub struct ChunkConfig { pub target_chars: usize, pub max_chars: usize, pub overlap_sentences: usize, pub cross_page: bool }`, with `Default` giving `800 / 1200 / 1 / false`
  - `pub struct Chunker<S: Source>` with `Chunker::new(source: S, document_name: String, cfg: ChunkConfig) -> Chunker<S>`, implementing `Iterator<Item = Result<Chunk>>`

**Rust notes for this task:**

- `Vec<&str>` from `split_sentences` returns *views into the input*, not copies. The compiler guarantees the input outlives the views — that is what lifetimes buy you, and it is why this costs nothing.
- Slicing a `&str` by byte index panics if the index is not a UTF-8 character boundary. The splitter only ever cuts at ASCII punctuation and whitespace, which are always boundaries, so it is safe. **This is a real Rust trap:** `&text[0..3]` on `"café"` compiles and then panics at runtime. When unsure, use `char_indices()`.
- `impl Iterator for Chunker` makes the type work with `for`, `.collect()` and `.map()`. Implementing `next()` is the whole contract, like writing `__next__` in Python.
- `S: Source` is a generic bound: `Chunker` works over any source and is monomorphized at compile time, so there is no dynamic dispatch cost.
- `VecDeque` is a double-ended queue, used as the small output buffer because one input page can yield several chunks.
- `.chars().count()` is O(n) and is **not** `.len()`, which returns bytes. Sizes here are character counts, matching what a user means by "800 characters."

**What the Python version does, for contrast.** It chunks with `range(0, len(text), step)` over raw character offsets, so chunks begin and end mid-word and mid-sentence. It then attributes pages with `min(idx, len(base_meta) - 1)` — not a lookup but a clamp, meaning every chunk past the first few is labelled with the document's last page. Retrieval built on that cannot cite sources correctly even with a perfect embedding model. This task fixes both: sentences are never split, and page spans are carried as real data.

```rust
//! Structure-aware chunking.
//!
//! Chunks break on sentence boundaries, never mid-sentence, and carry the
//! real page numbers and block ids their text came from.

use std::collections::VecDeque;

use crate::error::Result;
use crate::model::{BlockRef, Chunk, Page, PageOrigin};
use crate::normalize::normalize_block_text;
use crate::source::Source;

/// Splits on `.`, `!` and `?` when followed by whitespace or end of input,
/// absorbing trailing quotes and brackets so `he said "stop."` stays whole.
///
/// Deliberately simple: no abbreviation dictionary, no locale rules. It
/// cuts only at ASCII punctuation, so every byte index it produces is a
/// valid UTF-8 boundary.
pub fn split_sentences(text: &str) -> Vec<&str> {
    let bytes = text.as_bytes();
    let mut out = Vec::new();
    let mut start = 0usize;
    let mut i = 0usize;

    while i < bytes.len() {
        if matches!(bytes[i], b'.' | b'!' | b'?') {
            let mut end = i + 1;
            while end < bytes.len()
                && matches!(
                    bytes[end],
                    b'.' | b'!' | b'?' | b'"' | b'\'' | b')' | b']'
                )
            {
                end += 1;
            }

            if end >= bytes.len() || bytes[end].is_ascii_whitespace() {
                let piece = text[start..end].trim();
                if !piece.is_empty() {
                    out.push(piece);
                }
                start = end;
                i = end;
                continue;
            }
        }
        i += 1;
    }

    let tail = text[start..].trim();
    if !tail.is_empty() {
        out.push(tail);
    }

    out
}
```

```rust
    pub target_chars: usize,
    /// Hard ceiling. Only a single oversized sentence can trigger a cut.
    pub max_chars: usize,
    /// How many trailing sentences repeat at the start of the next chunk.
    pub overlap_sentences: usize,
    /// When false a chunk never spans pages, so page attribution is exact.
    pub cross_page: bool,
}

    fn default() -> Self {

            max_chars: 1200,
            overlap_sentences: 1,
            cross_page: false,

    }

}

pub struct Chunker<S: Source> {
    source: S,
    document: String,
    cfg: ChunkConfig,
    /// Sentences read but not yet emitted. Bounded by one page's text,
    /// which is what makes the memory ceiling structural rather than tuned.
    pending: Vec<Sentence>,
    ready: VecDeque<Chunk>,
    next_id: u64,
    exhausted: bool,
}

impl<S: Source> Chunker<S> {
    pub fn new(source: S, document_name: String, cfg: ChunkConfig) -> Self {
        Self {
            source,
            document: document_name,
            cfg,
            pending: Vec::new(),
            ready: VecDeque::new(),
            next_id: 0,
            exhausted: false,
        }
    }

    fn ingest(&mut self, page: Page) {
        for block in &page.blocks {
            let normalized = normalize_block_text(&block.text);
            for sentence in split_sentences(&normalized) {
                self.pending.push(Sentence {
                    text: sentence.to_string(),
                    page: page.number,
                    block: block.id,
                    origin: page.origin,
                });
            }
        }
    }

    fn push_chunk(&mut self, text: String, parts: &[Sentence], hard_split: bool) {
        let page_start = parts.iter().map(|s| s.page).min().unwrap_or(0);
        let page_end = parts.iter().map(|s| s.page).max().unwrap_or(0);

        let mut blocks: Vec<BlockRef> = Vec::new();
        for s in parts {
            let r = BlockRef {
                page: s.page,
                block: s.block,
            };
            if blocks.last() != Some(&r) {
                blocks.push(r);
            }
        }

        let origin = parts.first().map(|s| s.origin).unwrap_or(PageOrigin::Native);

        self.ready.push_back(Chunk {
            id: self.next_id,
            source: self.document.clone(),
            page_start,
            page_end,
            blocks,
            text,
            origin,
            hard_split,
        });
        self.next_id += 1;
    }

    /// Emits chunks from `pending`. When `flush` is false, stops as soon as
    /// the remainder is too small to reach `target_chars`, so the next page
    /// can contribute to it.
    fn drain(&mut self, flush: bool) {
        loop {
            if self.pending.is_empty() {
                return;
            }

            // An oversized lone sentence is the only thing ever cut.
            if self.pending[0].text.chars().count() > self.cfg.max_chars {
                let s = self.pending.remove(0);
                for piece in hard_split(&s.text, self.cfg.max_chars) {
                    self.push_chunk(piece, std::slice::from_ref(&s), true);
                }
                continue;
            }

            let mut take = 0usize;
            let mut len = 0usize;
            for s in &self.pending {
                let n = s.text.chars().count();
                let added = if take == 0 { n } else { n + 1 }; // +1 for the joining space
                if take > 0 && len + added > self.cfg.target_chars {
                    break;
                }
                len += added;
                take += 1;
                if len >= self.cfg.target_chars {
                    break;
                }
            }

            if len < self.cfg.target_chars && !flush {
                return; // wait for the next page to top it up
            }

            let used: Vec<Sentence> = self.pending.drain(..take).collect();
            let text = used
                .iter()
                .map(|s| s.text.as_str())
                .collect::<Vec<_>>()
                .join(" ");
            self.push_chunk(text, &used, false);

            // Re-queue overlap only when more text actually follows. This
            // guard is load-bearing twice: it prevents a final chunk made
            // purely of repeated overlap, and it guarantees termination,
            // because `take > k` means each pass consumes new input.
            if !self.pending.is_empty() {
                let k = self.cfg.overlap_sentences.min(used.len());
                if k > 0 && take > k {
                    for s in used[used.len() - k..].iter().rev() {
                        self.pending.insert(0, s.clone());
                    }
                }
            }
        }
    }
}

impl<S: Source> Iterator for Chunker<S> {
    type Item = Result<Chunk>;

    fn next(&mut self) -> Option<Self::Item> {
        loop {
            if let Some(chunk) = self.ready.pop_front() {
                return Some(Ok(chunk));
            }

            if self.exhausted {
                if self.pending.is_empty() {
                    return None;
                }
                self.drain(true);
                continue;
            }

            match self.source.next_page() {
                None => {
                    self.exhausted = true;
                    self.drain(true);
                }
                Some(Err(e)) => {
                    self.exhausted = true;
                    return Some(Err(e));
                }
                Some(Ok(page)) => {
                    self.ingest(page);
                    // Not crossing pages means flushing at every page
                    // boundary, which is exactly what keeps attribution exact.
                    self.drain(!self.cfg.cross_page);
                }
            }
        }
    }
}

/// Cuts an oversized sentence into `max_chars`-sized pieces on character
/// boundaries. Byte slicing would panic on multibyte text.
fn hard_split(text: &str, max_chars: usize) -> Vec<String> {
    let chars: Vec<char> = text.chars().collect();
    chars
        .chunks(max_chars.max(1))
        .map(|c| c.iter().collect())
        .collect()
}
```

After this task the project is a usable tool. DOCX only for now; Task 6 adds PDF behind the same interface without touching this file.

- Create: `docparse/docparse-cli/Cargo.toml`
- Create: `docparse/docparse-cli/src/main.rs`
- Create: `docparse/docparse-cli/tests/cli_test.rs`

**Interfaces:**
- Consumes: `DocxSource`, `Chunker`, `ChunkConfig`, `Error`, `Source` from Tasks 1–4.
- Produces:
  - `fn open_source(path: &Path) -> Result<Box<dyn Source>>` — the single dispatch point every later backend registers with
  - `fn collect_inputs(paths: &[PathBuf]) -> Vec<PathBuf>` — walks directories, keeps supported extensions
  - `fn run(args: &Args, out: &mut dyn Write) -> Outcome`, where `enum Outcome { AllOk, Partial, AllFailed }` maps to exit codes 0, 2, 1

**Rust notes for this task:**

- `Box<dyn Source>` is *dynamic dispatch*: a heap-allocated value behind a pointer whose concrete type is decided at runtime. `Chunker<S>` uses a generic (static dispatch, zero cost) because the type is known at compile time; the CLI cannot know whether it is opening a DOCX or a PDF, so it needs `dyn`. Both exist because they solve different problems — this is the one place the distinction becomes concrete.
- `dyn Source` requires `Source` to be *object safe*, which it is: one method, no generics, no `Self` in the return type. That was worth getting right in Task 1.
- `clap` with `#[derive(Parser)]` generates argument parsing and `--help` from a struct. The struct *is* the CLI specification.
- `impl Write` / `&mut dyn Write` lets `run` write to a file in production and to a `Vec<u8>` in tests, so the tests never touch the filesystem for output. This is why `run` takes a writer rather than opening one itself.
- `eprintln!` writes to stderr. Errors go there; only JSONL goes to stdout, so `docparse x.docx | jq` works.

**Design decision worth stating now, because Task 7 depends on it.** JSONL goes to stdout by default so the tool composes in a pipeline; `--output` redirects to a file. Errors always go to stderr and never into the JSONL stream, because a consumer parsing the output should never have to distinguish data from diagnostics. A failed file does not stop the batch — that is the spec's per-file isolation — and the exit code reports what happened overall.

```rust
//! The `docparse` command.
//!
//! JSONL on stdout, diagnostics on stderr, exit code summarising the batch.

use std::io::{BufWriter, Write};
use std::path::{Path, PathBuf};

use clap::{Parser, ValueEnum};
use docparse::chunk::{ChunkConfig, Chunker};
use docparse::{Error, Result, Source};
use walkdir::WalkDir;

#[derive(Debug, Clone, Copy, PartialEq, Eq, ValueEnum)]
enum Emit {
    /// Sentence-boundary chunks, the default.
    Chunks,
    /// Raw blocks, for callers who want to chunk themselves.
    Blocks,
}

#[derive(Debug, Parser)]
#[command(
    name = "docparse",
    about = "Extract structure-preserving JSONL from documents. Offline, no models."
)]
struct Args {
    /// Files or directories to process. Directories are walked recursively.
    #[arg(required = true)]
    paths: Vec<PathBuf>,

    /// Write JSONL here instead of stdout.
    #[arg(short, long)]
    output: Option<PathBuf>,

    /// Target chunk size in characters.
    #[arg(long, default_value_t = 800)]
    chunk: usize,

    /// Hard ceiling in characters; only an oversized sentence is ever cut.
    #[arg(long, default_value_t = 1200)]
    max_chunk: usize,

    /// Sentences repeated between consecutive chunks.
    #[arg(long, default_value_t = 1)]
    overlap: usize,

    /// Allow a chunk to span pages. Off by default so page attribution is exact.
    #[arg(long)]
    cross_page: bool,

    /// What to emit.
    #[arg(long, value_enum, default_value_t = Emit::Chunks)]
    emit: Emit,
}

fn main() {
    let args = Args::parse();

    let mut sink: Box<dyn Write> = match &args.output {
        Some(path) => match std::fs::File::create(path) {
            Ok(file) => Box::new(BufWriter::new(file)),
            Err(e) => {
                eprintln!("error: cannot write {}: {e}", path.display());
                std::process::exit(1);
            }
        },
        None => Box::new(BufWriter::new(std::io::stdout())),
    };

    let outcome = run(&args, &mut sink);

    if let Err(e) = sink.flush() {
        eprintln!("error: could not flush output: {e}");
        std::process::exit(1);
    }

    std::process::exit(match outcome {
        Outcome::AllOk => 0,
        Outcome::AllFailed => 1,
        Outcome::Partial => 2,
    });
}

enum Outcome {
    AllOk,
    Partial,
    AllFailed,
}

/// Extensions we know how to open. Kept in one place so `collect_inputs`
/// and `open_source` cannot drift apart.
const SUPPORTED: &[&str] = &["docx", "pdf", "png", "jpg", "jpeg", "webp", "bmp", "tif", "tiff"];

fn run(args: &Args, out: &mut dyn Write) -> Outcome {
    let inputs = collect_inputs(&args.paths);

    if inputs.is_empty() {
        eprintln!("error: no supported documents found in the given paths");
        return Outcome::AllFailed;
    }

    let cfg = ChunkConfig {
        target_chars: args.chunk,
        max_chars: args.max_chunk,
        overlap_sentences: args.overlap,
        cross_page: args.cross_page,
    };

    let mut ok = 0usize;
    let mut failed = 0usize;

    for path in &inputs {
        match process_file(path, args.emit, cfg, out) {
            Ok(()) => ok += 1,
            Err(e) => {
                // Per-file isolation: report and keep going.
                eprintln!("error: {e}");
                failed += 1;
            }
        }
    }

    match (ok, failed) {
        (_, 0) => Outcome::AllOk,
        (0, _) => Outcome::AllFailed,
        _ => Outcome::Partial,
    }
}

fn process_file(path: &Path, emit: Emit, cfg: ChunkConfig, out: &mut dyn Write) -> Result<()> {
    let source = open_source(path)?;
    let name = path
        .file_name()
        .map(|n| n.to_string_lossy().into_owned())
        .unwrap_or_else(|| path.to_string_lossy().into_owned());

    let io_err = |e: std::io::Error| Error::Io {
        path: path.to_path_buf(),
        source: e,
    };

    match emit {
        Emit::Chunks => {
            for chunk in Chunker::new(source, name, cfg) {
                let chunk = chunk?;
                let line = serde_json::to_string(&chunk).map_err(|e| Error::Malformed {
                    path: path.to_path_buf(),
                    detail: format!("could not serialize chunk {}: {e}", chunk.id),
                })?;
                writeln!(out, "{line}").map_err(io_err)?;
            }
        }
        Emit::Blocks => {
            let mut source = source;
            while let Some(page) = source.next_page() {
                let page = page?;
                for block in &page.blocks {
                    // Flatten the page number into each block so a single
                    // JSONL line is self-describing.
                    let mut value = serde_json::to_value(block).map_err(|e| Error::Malformed {
                        path: path.to_path_buf(),
                        detail: format!("could not serialize block: {e}"),
                    })?;
                    if let Some(map) = value.as_object_mut() {
                        map.insert("page".into(), page.number.into());
                        map.insert("source".into(), name.clone().into());
                    }
                    writeln!(out, "{value}").map_err(io_err)?;
                }
            }
        }
    }

    Ok(())
}

/// The single dispatch point. Every backend task registers here and
/// nothing else in the CLI needs to know which formats exist.
fn open_source(path: &Path) -> Result<Box<dyn Source>> {
    let ext = path
        .extension()
        .map(|e| e.to_string_lossy().to_lowercase())
        .unwrap_or_default();

    match ext.as_str() {
        #[cfg(feature = "docparse/docx")]
        "docx" => Ok(Box::new(docparse::docx::DocxSource::open(path)?)),

        _ => Err(Error::Unsupported {
            path: path.to_path_buf(),
        }),
    }
}

fn collect_inputs(paths: &[PathBuf]) -> Vec<PathBuf> {
    let mut found = Vec::new();

    for path in paths {
        if path.is_dir() {
            for entry in WalkDir::new(path).sort_by_file_name() {
                let Ok(entry) = entry else { continue };
                if entry.file_type().is_file() && is_supported(entry.path()) {
                    found.push(entry.path().to_path_buf());
                }
            }
        } else {
            // An explicitly named file is attempted even if the extension
            // is unknown, so the user gets a real error rather than silence.
            found.push(path.clone());
        }
    }

    found
}

fn is_supported(path: &Path) -> bool {
    path.extension()
        .map(|e| SUPPORTED.contains(&e.to_string_lossy().to_lowercase().as_str()))
        .unwrap_or(false)
}
```

```rust
//! PDF extraction via PDFium.
//!
//! Streams one page at a time: the document handle stays open and each
//! `next_page` call renders exactly one page's text, so peak memory is a
//! function of the largest page rather than the document.

use std::path::{Path, PathBuf};

use pdfium_render::prelude::*;

use crate::error::{Error, Result};
use crate::model::{Block, BlockKind, Page, PageOrigin, Rect};
use crate::normalize::normalize_block_text;
use crate::source::Source;

pub struct PdfSource {
    path: PathBuf,
    /// Owned, not borrowed: C handles and borrow-checked lifetimes do not
    /// mix comfortably, and owning sidesteps the problem entirely.
    pdfium: Pdfium,
    document: PdfDocument<'static>,
    next_index: u16,
    page_count: u16,
}

impl PdfSource {
    pub fn open(path: &Path) -> Result<Self> {
        if !path.exists() {
            return Err(Error::Io {
                path: path.to_path_buf(),
                source: std::io::Error::new(std::io::ErrorKind::NotFound, "no such file"),
            });
        }

        let pdfium = Pdfium::new(Pdfium::bind_to_system_library().map_err(|e| {
            Error::Malformed {
                path: path.to_path_buf(),
                detail: format!("PDFium library unavailable: {e}"),
            }
        })?);

        let document = pdfium
            .load_pdf_from_file(path, None)
            .map_err(|e| Error::Malformed {
                path: path.to_path_buf(),
                detail: format!("could not open as PDF: {e}"),
            })?;

        let page_count = document.pages().len();

        // SAFETY-equivalent note: `document` borrows `pdfium`, and both are
        // moved into the same struct, so the borrow can never dangle. If the
        // borrow checker rejects this shape, use the `Pdfium::bind_*` guard
        // pattern from the crate docs instead of reaching for `unsafe`.
        Ok(Self {
            path: path.to_path_buf(),
            pdfium,
            document,
            next_index: 0,
            page_count,
        })
    }

    fn read_page(&self, index: u16) -> Result<Page> {
        let page = self
            .document
            .pages()
            .get(index)
            .map_err(|e| Error::Page {
                path: self.path.clone(),
                page: u32::from(index) + 1,
                detail: e.to_string(),
            })?;

        let width = page.width().value;
        let height = page.height().value;

        let text = page.text().map_err(|e| Error::Page {
            path: self.path.clone(),
            page: u32::from(index) + 1,
            detail: format!("could not read text: {e}"),
        })?;

        let mut blocks: Vec<Block> = Vec::new();
        for segment in text.segments().iter() {
            let raw = segment.text();
            let cleaned = normalize_block_text(&raw);
            if cleaned.is_empty() {
                continue;
            }

            let bounds = segment.bounds();
            blocks.push(Block {
                id: blocks.len() as u32,
                bbox: Some(Rect {
                    x0: bounds.left().value,
                    y0: bounds.bottom().value,
                    x1: bounds.right().value,
                    y1: bounds.top().value,
                }),
                kind: BlockKind::Paragraph,
                text: cleaned,
            });
        }

        Ok(Page {
            number: u32::from(index) + 1,
            width,
            height,
            origin: PageOrigin::Native,
            blocks,
        })
    }
}

impl Source for PdfSource {
    fn next_page(&mut self) -> Option<Result<Page>> {
        if self.next_index >= self.page_count {
            return None;
        }
        let index = self.next_index;
        self.next_index += 1;
        Some(self.read_page(index))
    }
}
```

**Expect the borrow checker to argue with the `PdfDocument<'static>` field.** A struct holding both an owner and something borrowed from it is self-referential, which Rust forbids, and `'static` is a lie that will not type-check. Resolve it one of these ways, in order of preference:

1. Check whether the installed `pdfium-render` version offers an owned document type or a `'static` binding helper — recent versions do, and this is then a non-issue.
2. Make `pdfium` a process-wide singleton with `std::sync::OnceLock<Pdfium>`, and have `PdfSource` hold `PdfDocument<'static>` borrowed from that genuinely-static instance. This is the clean fix and is what the crate's own examples do.
3. Only if neither works: collect page numbers eagerly and reopen the document per page. Correct but slow; do not ship this without saying so.

Option 2 in practice:

```rust
use std::sync::OnceLock;

static PDFIUM: OnceLock<Pdfium> = OnceLock::new();

fn pdfium() -> Result<&'static Pdfium> {
    // `bind_to_system_library` is cheap to call once and must not be
    // repeated per document.
    if let Some(p) = PDFIUM.get() {
        return Ok(p);
    }
    let bindings = Pdfium::bind_to_system_library().map_err(|e| Error::Malformed {
        path: PathBuf::from("<pdfium>"),
        detail: format!("PDFium library unavailable: {e}"),
    })?;
    Ok(PDFIUM.get_or_init(|| Pdfium::new(bindings)))
}
```

`PdfSource` then drops its `pdfium` field and holds `document: PdfDocument<'static>` obtained from `pdfium()?.load_pdf_from_file(...)`.

### Task 7: Parallelism across files, and the memory ceiling test

This is the task where the low-end-hardware goal stops being an assertion and becomes a test.

**Files:**

**Interfaces:**
- Consumes: everything from Tasks 1–6.
- Produces: `--jobs N` on the CLI; `run` unchanged in signature, parallel inside.

**Rust notes for this task:**

- `rayon`'s `par_iter()` turns a sequential iterator into a parallel one with a work-stealing thread pool. `.into_par_iter().map(...).collect()` is the whole API you need here.
- `Mutex<T>` grants one thread at a time access to the value inside. `lock().unwrap()` returns a guard; the lock releases when the guard is dropped at the end of its scope. There is no `try/finally` because there is no way to forget.
- A mutex in Rust wraps *the data*, not a region of code. You cannot read the protected value without taking the lock — the type system enforces the discipline that a `threading.Lock` in Python only documents.
- `available_parallelism()` is the standard-library core count. We deliberately cap it.
- A *global allocator* can be swapped out, which is how `peak_alloc` measures the high-water mark of every allocation the process makes.

**The ordering trade-off, stated rather than hidden.** With `--jobs 1`, output is byte-identical across runs, which the determinism constraint requires. With `--jobs N`, each worker holds the output lock for the whole of its file, so a file's lines stay contiguous and correctly ordered, but *files* appear in completion order rather than input order. The alternative — buffering every file's output to restore input order — would make peak memory scale with total corpus size, which contradicts the project's entire premise. So: parallel output is grouped-but-unordered by design, the determinism test runs with `--jobs 1`, and `--help` says so. This is a refinement of the spec's determinism clause, not a violation of it; update the spec's Section 4 wording when this task lands.

```rust
//! Asserts the spec's 64 MB budget. This measures peak *heap allocation*
//! via a tracking global allocator, not RSS: it excludes the binary, thread
//! stacks and any C-library allocations PDFium makes internally. That makes
//! it a tight, deterministic proxy rather than the whole truth, which is
//! the right trade for a test that must not flake.

use docparse::chunk::{ChunkConfig, Chunker};
use docparse::model::{Block, BlockKind, Page, PageOrigin};
use docparse::{Result, Source};
use peak_alloc::PeakAlloc;

#[global_allocator]
static ALLOC: PeakAlloc = PeakAlloc;

const CEILING_BYTES: f32 = 64.0 * 1024.0 * 1024.0;

/// Synthesizes pages on demand without ever holding them all, so the test
/// harness itself cannot be what blows the budget.
struct HugeDocument {
    pages_remaining: u32,
    next_number: u32,
    blocks_per_page: usize,
}

impl Source for HugeDocument {
    fn next_page(&mut self) -> Option<Result<Page>> {
        if self.pages_remaining == 0 {
            return None;
        }
        self.pages_remaining -= 1;
        let number = self.next_number;
        self.next_number += 1;

        let blocks = (0..self.blocks_per_page)
            .map(|i| Block {
                id: i as u32,
                bbox: None,
                kind: BlockKind::Paragraph,
                text: format!(
                    "Page {number} block {i}. {}",
                    "This is filler prose that exists to occupy space. ".repeat(12)
                ),
            })
            .collect();

        Some(Ok(Page {
            number,
            width: 612.0,
            height: 792.0,
            origin: PageOrigin::Native,
            blocks,
        }))
    }
}

#[test]
fn a_five_thousand_page_document_stays_under_the_ceiling() {
    ALLOC.reset_peak_usage();

    let source = HugeDocument {
        pages_remaining: 5_000,
        next_number: 1,
        blocks_per_page: 20,
    };

    // Consume every chunk and keep nothing: this is how the CLI uses it.
    let mut count = 0usize;
    let mut total_chars = 0usize;
    for chunk in Chunker::new(source, "huge.pdf".to_string(), ChunkConfig::default()) {
        let chunk = chunk.unwrap();
        count += 1;
        total_chars += chunk.text.chars().count();
    }

    let peak = ALLOC.peak_usage() as f32;

    assert!(count > 1_000, "expected many chunks, got {count}");
    assert!(total_chars > 1_000_000, "expected a large document");
    assert!(
        peak < CEILING_BYTES,
        "peak heap {:.1} MB exceeded the {:.0} MB ceiling after {count} chunks",
        peak / 1024.0 / 1024.0,
        CEILING_BYTES / 1024.0 / 1024.0
    );
}

#[test]
fn peak_memory_does_not_grow_with_document_length() {
    // The real property: ten times the pages must not mean ten times the
    // memory. A ceiling test alone could pass by luck on a small input.
    let measure = |pages: u32| -> f32 {
        ALLOC.reset_peak_usage();
        let source = HugeDocument {
            pages_remaining: pages,
            next_number: 1,
            blocks_per_page: 20,
        };
        for chunk in Chunker::new(source, "doc.pdf".to_string(), ChunkConfig::default()) {
            let _ = chunk.unwrap();
        }
        ALLOC.peak_usage() as f32
    };

    let small = measure(100);
    let large = measure(2_000);

    assert!(
        large < small * 3.0,
        "memory grew with document length: {:.1} MB for 100 pages vs {:.1} MB for 2000",
        small / 1024.0 / 1024.0,
        large / 1024.0 / 1024.0
    );
}
```

```rust
fn run(args: &Args, out: &mut dyn Write) -> Outcome {
    let inputs = collect_inputs(&args.paths);

    if inputs.is_empty() {
        eprintln!("error: no supported documents found in the given paths");
        return Outcome::AllFailed;
    }

    let cfg = ChunkConfig {
        target_chars: args.chunk,
        max_chars: args.max_chunk,
        overlap_sentences: args.overlap,
        cross_page: args.cross_page,
    };

    // Deliberately not all cores: on a 2-core machine that is
    // oversubscription, and on an HDD the disk is the bottleneck anyway.
    let jobs = args.jobs.unwrap_or_else(|| {
        std::thread::available_parallelism()
            .map(|n| n.get().min(4))
            .unwrap_or(1)
    });

    if jobs <= 1 {
        let mut ok = 0usize;
        let mut failed = 0usize;
        for path in &inputs {
            match process_file(path, args.emit, cfg, out) {
                Ok(()) => ok += 1,
                Err(e) => {
                    eprintln!("error: {e}");
                    failed += 1;
                }
            }
        }
        return summarise(ok, failed);
    }

    // The writer is shared, so it is behind a mutex. Each worker holds the
    // lock for the whole of its file, keeping that file's lines contiguous.
    let sink = Mutex::new(out);

    let pool = match rayon::ThreadPoolBuilder::new().num_threads(jobs).build() {
        Ok(pool) => pool,
        Err(e) => {
            eprintln!("error: could not start {jobs} workers: {e}");
            return Outcome::AllFailed;
        }
    };

    let results: Vec<std::result::Result<(), String>> = pool.install(|| {
        inputs
            .par_iter()
            .map(|path| {
                let mut buffer: Vec<u8> = Vec::new();
                // Buffer one file, not the corpus: bounded by a single
                // document's output, which the memory test covers.
                match process_file(path, args.emit, cfg, &mut buffer) {
                    Ok(()) => {
                        let mut guard = sink.lock().expect("output mutex poisoned");
                        guard
                            .write_all(&buffer)
                            .map_err(|e| format!("{}: writing output: {e}", path.display()))
                    }
                    Err(e) => Err(e.to_string()),
                }
            })
            .collect()
    });

    let mut ok = 0usize;
    let mut failed = 0usize;
    for result in results {
        match result {
            Ok(()) => ok += 1,
            Err(message) => {
                eprintln!("error: {message}");
                failed += 1;
            }
        }
    }

    summarise(ok, failed)
}

fn summarise(ok: usize, failed: usize) -> Outcome {
    match (ok, failed) {
        (_, 0) => Outcome::AllOk,
        (0, _) => Outcome::AllFailed,
        _ => Outcome::Partial,
    }
}
```

and add the imports:

```rust
use std::sync::Mutex;

use rayon::prelude::*;
```

**Note the one real compromise in the parallel path:** each worker buffers its own file's output in memory before taking the lock, so the lock is held briefly rather than for the duration of parsing. That buffer is bounded by one document's JSONL, not the corpus — consistent with the per-file ceiling, and the reason `--jobs 1` streams without buffering at all. If a single document's output ever threatens the budget, the fix is to hold the lock across the parse for that file; do not add a second buffering layer.

```rust
//! OCR via the `tesseract` executable.
//!
//! Shelling out rather than linking `libtesseract`: linking requires
//! Leptonica and Tesseract development headers, which is a significant
//! build burden on Windows, while the process-spawn cost is negligible
//! next to the OCR itself.

use std::path::Path;

use crate::error::{Error, Result};

/// Returns the recognized text and a mean confidence in `0.0..=1.0`.
pub fn ocr_image_file(path: &Path) -> Result<(String, f32)> {
    let image = rusty_tesseract::Image::from_path(path).map_err(|e| Error::Malformed {
        path: path.to_path_buf(),
        detail: format!("could not load image for OCR: {e}"),
    })?;

    let args = rusty_tesseract::Args::default();

    let text = rusty_tesseract::image_to_string(&image, &args).map_err(|e| Error::Malformed {
        path: path.to_path_buf(),
        detail: format!("OCR failed: {e}"),
    })?;

    // Tesseract reports per-word confidences on a 0-100 scale. Averaging
    // them gives a usable page-level signal; absent any words we report
    // zero rather than a flattering default.
    let confidence = rusty_tesseract::image_to_data(&image, &args)
        .ok()
        .map(|data| {
            let values: Vec<f32> = data
                .data
                .iter()
                .filter(|d| d.conf >= 0.0 && !d.text.trim().is_empty())
                .map(|d| d.conf)
                .collect();
            if values.is_empty() {
                0.0
            } else {
                (values.iter().sum::<f32>() / values.len() as f32 / 100.0).clamp(0.0, 1.0)
            }
        })
        .unwrap_or(0.0);

    Ok((text, confidence))
}
```

Field names on `rusty_tesseract`'s data rows have varied between releases. Verify with `cargo doc -p rusty-tesseract --no-deps --open` and adjust `d.conf` / `d.text` if needed; the structure of the function is what matters.

```rust
//! Image input. An image is always a single page, and always OCR.

use std::path::{Path, PathBuf};

use crate::error::{Error, Result};
use crate::model::{Block, BlockKind, Page, PageOrigin};
use crate::normalize::normalize_block_text;
use crate::source::Source;

pub struct ImageSource {
    page: Option<Page>,
}

impl ImageSource {
    pub fn open(path: &Path) -> Result<Self> {
        // Decode first, so a corrupt file fails here with a clear error
        // rather than inside the OCR subprocess.
        let decoded = image::open(path).map_err(|e| Error::Malformed {
            path: path.to_path_buf(),
            detail: format!("could not decode image: {e}"),
        })?;

        let (width, height) = (decoded.width() as f32, decoded.height() as f32);
        drop(decoded); // the pixels are not needed again; tesseract re-reads the file

        let page = Self::ocr_page(path, width, height)?;
        Ok(Self { page: Some(page) })
    }

    #[cfg(feature = "ocr")]
    fn ocr_page(path: &Path, width: f32, height: f32) -> Result<Page> {
        let (text, confidence) = crate::ocr::ocr_image_file(path)?;
        let cleaned = normalize_block_text(&text);

        let blocks = if cleaned.is_empty() {
            Vec::new()
        } else {
            vec![Block {
                id: 0,
                bbox: None, // whole-page OCR gives no per-block geometry
                kind: BlockKind::Other,
                text: cleaned,
            }]
        };

        Ok(Page {
            number: 1,
            width,
            height,
            origin: PageOrigin::Ocr { confidence },
            blocks,
        })
    }

    #[cfg(not(feature = "ocr"))]
    fn ocr_page(path: &Path, _width: f32, _height: f32) -> Result<Page> {
        // An image without OCR has no text to give. Saying so is the
        // whole policy; returning an empty page would be a silent lie.
        Err(Error::OcrUnavailable {
            path: PathBuf::from(path),
        })
    }
}

impl Source for ImageSource {
    fn next_page(&mut self) -> Option<Result<Page>> {
        self.page.take().map(Ok)
    }
}
```

**Rust notes for this task:**

- `criterion` runs each benchmark many times, discards warm-up, and reports a confidence interval — so a 5% difference is distinguishable from noise, unlike a single `time` run.
- `black_box(x)` stops the optimizer from deleting work whose result is unused. Without it, a benchmark that computes and discards can be optimized to nothing and report an impossibly fast time. **If a benchmark reports nanoseconds, this is almost always why.**
- Benchmarks must be built in release mode; `cargo bench` does that automatically, but a debug-mode measurement is meaningless and off by an order of magnitude.

```rust
use std::path::PathBuf;

use criterion::{criterion_group, criterion_main, Criterion, Throughput};
use docparse::chunk::{ChunkConfig, Chunker};
use docparse::model::{Block, BlockKind, Page, PageOrigin};
use docparse::{Result, Source};

/// A synthetic source, so chunker throughput is measured without disk or
/// PDF-parsing noise in the number.
struct Synthetic {
    remaining: u32,
    number: u32,
}

impl Source for Synthetic {
    fn next_page(&mut self) -> Option<Result<Page>> {
        if self.remaining == 0 {
            return None;
        }
        self.remaining -= 1;
        self.number += 1;
        Some(Ok(Page {
            number: self.number,
            width: 612.0,
            height: 792.0,
            origin: PageOrigin::Native,
            blocks: (0..8)
                .map(|i| Block {
                    id: i,
                    bbox: None,
                    kind: BlockKind::Paragraph,
                    text: "This is a representative sentence of body prose. ".repeat(8),
                })
                .collect(),
        }))
    }
}

fn chunker_throughput(c: &mut Criterion) {
    const PAGES: u32 = 500;
    let mut group = c.benchmark_group("chunker");
    group.throughput(Throughput::Elements(u64::from(PAGES)));

    group.bench_function("500_synthetic_pages", |b| {
        b.iter(|| {
            let source = Synthetic {
                remaining: PAGES,
                number: 0,
            };
            let mut count = 0usize;
            for chunk in Chunker::new(source, "bench".to_string(), ChunkConfig::default()) {
                // black_box keeps the optimizer from deleting the work.
                black_box(chunk.unwrap());
                count += 1;
            }
            black_box(count)
        })
    });
    group.finish();
}
```

```python
"""Times the existing Python pipeline's extraction + chunking on a corpus,
for an honest side-by-side with docparse.

Measures only extraction and chunking. It deliberately does not touch
embedding, FAISS, Ollama or BLIP, because docparse does not do those
things and including them would make the comparison flattering rather
than informative.

Usage:  .venv/Scripts/python docparse/scripts/baseline.py <corpus-dir>
"""

from __future__ import annotations

import sys
import time
import tracemalloc
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[2]))

from backend.services.ingestion import IngestionService
from backend.services.vision import VisionService


def main() -> int:
    if len(sys.argv) != 2:
        print(__doc__)
        return 2

    corpus = Path(sys.argv[1])
    files = sorted(
        p
        for p in corpus.rglob("*")
        if p.suffix.lower() in IngestionService.SUPPORTED_EXTENSIONS
    )
    if not files:
        print(f"no supported documents under {corpus}")
        return 1

    # VisionService loads BLIP lazily and is only reached for images; the
    # corpus for a fair comparison should be PDFs and DOCX files.
    service = IngestionService(vision_service=VisionService())

    tracemalloc.start()
    started = time.perf_counter()
    chunks = 0
    failures = 0

    for path in files:
        try:
            produced, _meta = service.ingest_file(path)
            chunks += len(produced)
        except Exception as exc:  # per-file isolation, same as docparse
            failures += 1
            print(f"error: {path.name}: {exc}", file=sys.stderr)

    elapsed = time.perf_counter() - started
    _current, peak = tracemalloc.get_traced_memory()
    tracemalloc.stop()

    total_bytes = sum(p.stat().st_size for p in files)
    print(f"files      : {len(files)} ({failures} failed)")
    print(f"chunks     : {chunks}")
    print(f"elapsed    : {elapsed:.2f} s")
    print(f"throughput : {total_bytes / elapsed / 1_048_576:.2f} MB/s")
    print(f"peak python heap: {peak / 1_048_576:.1f} MB")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
